# 打手端生产问题修复交付记录

日期：2026-10-18。工作区：`codex/production-fixes-20261018`。本文件只记录本轮独立客户端实现及隔离验收；正式站更新由用户审核后执行。

## 交付行为

- 订单的原履约状态保留，展示优先使用服务端 `displayStatus`。任务增加存单、问题单、退款审批中、已退款筛选；完整退款、存单、退款审批暂停及未关闭问题单均不提供打手订单操作入口。
- 存单原因、恢复记录和“原负责人续做不占名额”直接展示服务端授权字段，不在客户端自行计算名额或恢复任务。
- 按用户最终纠正规则，存单和未关闭问题单期间打手仅可查看，交后台客服处理。问题详情保留原因、历史反馈和后台处理结果；已移除新反馈表单、调用入口及新反馈目标构造。后台客服记录处理结果并关闭，打手不能接受、拒绝、上报、申请退单或提交问题反馈；问题本身不释放名额。
- `playerOperationBlockedReason` 统一驱动客户端只读行为；旧投影缺字段时仍按 `problem.status==='open'`、存单及退款字段保守拦截。关闭问题只解除问题限制，不能解除存单或退款限制。大厅、详情、上传及原请求重试均遵守该规则。
- 原 `problem-feedback` 操作族仅保留历史未知结果的只读核对及换号隔离，不提供创建或重试写入能力，避免规则变更遗失旧成功凭据。
- 问题、存单恢复和退款消息先重新读取原通知和当前订单；同时比较 `problemId`、派单轮次、负责人接单身份和材料目标，旧消息不能恢复旧操作资格。
- 上传沿用既有图片预处理、明确进度、取消和账号保护，传输改为二进制图片及编码文件名，取消 Base64 传输膨胀。服务端保留旧 JSON 上传兼容。
- 私人图片、头像、卡片和板报采用认证衍生图，材料点击链接才读取原图。图片加载受四并发限制，会话内最多保留 48 项、12 MiB、60 秒；缓存与像素对象在账号/权限边界清理，没有 localStorage、Service Worker、离线缓存或自动重发。
- 原图 URL 不改写为衍生图元数据；收款码提供独立原图入口，展示采用 1600 像素衍生图。公开登录外观使用服务端受当前授权约束的 `display` 版本及条件缓存。

## 限制与发布衔接

RC3 补齐导航资源失败恢复：仅明确的动态模块/CSS错误触发提示，由用户点击后重新验证同源内置路由并刷新一次；不自动重发业务请求，不清除账号或未确认操作标记。六项新运行时测试及九项既有业务边界均通过；真实浏览器四组覆盖 320/390 主导航和“我的”八个子页、排行榜/我的分别跨版本旧脚本 404→取消→手动刷新→目标恢复，并保留未知提现标记，全程无业务写入。最新记录见 `docs/打手导航验收修正-RC3-2026-10-18.md`。

上述浏览器验证是桌面 Edge 的手机尺寸，不代表真实安卓/iPhone、锁屏、关闭网页后的推送到达或公司网络性能。服务器衍生图缩小了传输，实际雨云带宽、公司线路和真实凭证尺寸仍需要正式环境验收。

测试数据和图片仅存在隔离库及被忽略的 `.qa/` 输出中，不应进入更新包。后端契约、部署数据兼容、备份恢复及最终发布包由主任务统一收尾。

## 取消与退款简化补充验收

- 取消订单以原始 `status==='canceled'` 判定，从日常大厅、任务和列表计数中移除，避免“已退款”展示状态覆盖取消状态后漏掉。客户端 API 对旧/混合响应再次过滤，卡片组件也防御性拒绝渲染取消单；跨页总数仍由服务端权威计算，不在前端扫描或猜测其他页。
- 卡片、详情和双人报酬预览统一使用服务端 `effectiveReward`；旧投影缺字段时保留原 `reward`。是否未结算、部分退款或应保留已结算报酬均由服务端决定，前端不自行清零。详情可显示明确标注的原报酬历史，不提供特殊报酬修改表单。
- 新类型仅接收打手授权的 `rewardDisposition.mode/trigger/policyVersion`，不接收决策人、决策时间、客户退款金额或路线。取消详情缺新阻断字段时仍按原始取消状态只读；旧通知先重新读取当前订单，不能恢复操作资格。未知操作回执可继续只读核对，取消单不能重试旧写入，原防重标记保留。
- 本轮新增 `tests/cancellation-refund-runtime.test.mjs` 四项：服务端有效报酬与历史不变、展示状态覆盖时仍剔除取消、取消旧投影不能构造写入目标、实际 HTTP 重新读取后替换旧列表并保留只读详情。连同导航恢复六项、原生产修复九项及请求运行时十六项，共三十五项通过；新展示模块单独 ESLint 和客户端类型检查通过。
- 新真实浏览器 `tests/cancellation-refund-browser.mjs` 在主任务提供的独立 `player-rc4` 构建上完成五组：取消移除及 KeepAlive 返回、旧详情只读、真实旧通知只读、未结算全退零报酬/部分退款及已结算保留、空态及整页刷新。零页面错误和失败响应；浏览器仅提交一次通知已读，没有订单或资金写入。未知上报标记在导航和刷新后保留。
- 浏览器证据：`player-client/.qa/cancellation-refund-browser/results.json`、`canceled-readonly-390.png`。夹具仅使用新内存库、随机回环端口和假凭证，外部推送禁用。本子任务没有构建活跃产物、重启当前预览或更新正式站。
