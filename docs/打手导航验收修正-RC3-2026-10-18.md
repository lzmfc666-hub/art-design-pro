# 打手导航验收修正 RC3

本次处理“排行榜与我的无法进入”，在 RC2 上只修改打手端导航加载失败的恢复行为。退款、存单、问题单、资金和人员规则保持 RC2。正式雨云站未发布，原主分支和原业务数据未修改。

## 原因与处理

新开的本地浏览器中，排行榜和我的均能正常读取。隔离复现发现：旧页面已打开大厅，更新时若替换并删除旧构建文件，随后首次进入排行榜或我的，会请求已不存在的旧哈希脚本，返回 404，路由仍停在原页。两条入口都复现了这一现象。该证据解释本地验收现象，不代表已检查用户当时浏览器的缓存或正式服务器。

- 仅明确的动态模块或 CSS 加载失败会显示“页面暂时无法打开”。用户可以暂不刷新，或点击“刷新并打开页面”进入刚才选择的入口。
- 没有自动刷新、业务提交、自动重发或账号存储清理。刷新前提示未提交输入可能丢失，未确认资金操作的防重标记继续保留。
- 恢复目标只在内存保存，并经过同源、当前内置命名路由校验；点击时再次校验。成功导航后清除提示。
- 本地新预览构建先在独立目录完成，再切换服务；保留上一版生成的公共哈希资源。没有在活跃目录执行清空构建。正式更新也需要保留旧页面仍可能请求的哈希资源，入口 HTML 保持重新验证。
- 已经打开、尚不包含本修复的更早旧页面，需要手动刷新一次。新代码无法追溯改变旧页面已经运行的代码。
