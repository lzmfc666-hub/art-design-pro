二、采用已定稿读取契约

所有路径前缀为 /api/studio，沿用当前 studioRequest、同源认证 Cookie、账号边界及取消/合并读取机制。

GET /player/appearance
返回：{revision:number,orderCardImage:Attachment|null}
Attachment 为：{id,name,mime,size,url}
orderCardImage.url 为规范站内 /api/studio/uploads/:id；无图返回 null。该字段对应后台 AppearanceConfig.playerOrderCardImage，但打手只读取这份最小投影，不读取完整后台外观配置代替。

只允许当前启用且允许登录的打手读取。无、过期、撤销或关闭登录会话按现有认证返回 401；非打手返回 403；服务层同样核验启用与登录开关。读取不产生业务、资金、审计或通知。

GET /player/changes 新增 appearanceRevision:number，等于全局外观 revision。沿用原 version/changed；保存、替换、移除和恢复默认会推进现有变更版本。appearanceRevision 不是订单 revision、接单资格、钱包版本或操作校验值，不能用于任何业务写入。

JSON 响应为 Cache-Control:no-store。图片使用认证 GET /uploads/:id，响应为 Cache-Control:private,no-store。通过本站原认证图片 URL 显示，不改成匿名 public-assets，不转成 data URL 或持久化 Blob，不引入任意外链。

替换、移除或恢复默认后，旧图不能仅凭旧卡图配置继续共享。原上传人所有权、其他当前外观槽或合法业务权限另行裁决；文件或历史审计仍存在不代表当前共享授权。客户端只显示最新读取中的 orderCardImage，不自行探测旧图或寻找替代图。
