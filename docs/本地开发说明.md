# 金盾电竞工作室后台

基于 Art Design Pro 的 Vue 3 / TypeScript / Element Plus 前端，配套本地 Node.js API 和 SQLite 数据库。后台先开发，独立打手端后续接入，双方准备完成后再共同上线。

## 本地运行

需要 Node.js 24+、pnpm 11+。在项目目录运行：

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

浏览器访问 `http://127.0.0.1:3006`。前端端口 3006，后端端口 3007，默认只监听本机。

初始管理员账号为 `admin`。首次启动会随机生成初始密码，保存在 `.data/bootstrap-password.txt`。也可以在首次启动前用环境变量 `STUDIO_ADMIN_PASSWORD` 自行指定初始密码。该文件、数据库、上传图片、会话均不提交到 Git；不要将 `.data` 上传到公开仓库。

管理员在“用户管理”中新建员工及打手账号、设置密码和角色。初始开发管理员显式开启全部个人权限，其他账号遵循角色默认权限，可逐人覆盖。

```powershell
pnpm typecheck
pnpm test
pnpm build
pnpm start
```

`pnpm start` 运行后端并提供已构建的 `dist` 页面。正式部署另行配置服务域名、HTTPS、数据备份和运行管理，本次不发布到公网。

## 使用顺序

1. 游戏与业务配置：维护订单项目、客户价格、整单打手报酬、来源、闲鱼店铺及等级等待时间。
2. 用户管理：建立员工、打手和客户档案，设置打手等级、接单上限与权限。
3. 快捷下单：选择项目，补客户、来源、房间码或游戏 ID、备注和付款信息，再发布到抢单池或指派。
4. 打手通过预留接口接单并提交完成截图。后台不增加客服代接单或代上报功能。
5. 财务管理：验收、退款、提现审核及人工发放登记、费用、工资方案与工资月结。
6. 数据概览 / 财务报表核对经营数据，操作日志查看修改前后记录。

## 重要业务口径

- 所有金额以整数分保存，提成比例用万分比；平台订单号按文本保存。
- 客户实际付款日、订单完成月份、退款实际发生时间分别记录。经营收入、退款和相关订单成本回归原付款日，工资提成按完成月份归属。
- 财务验收前的打手报酬为约定 / 预计成本；验收通过才形成可提现报酬。提现发放不再次扣经营成本。
- 订单取消与实际退款分别处理；有执行历史的取消订单保留约定成本，直到财务确认补偿。
- 客服与客服主管默认只看本人业绩，不开放工资。利润、工资、接口返回与日志均按权限限制。
- 底薪及提成比例缺失时显示“待配置 / 统计不完整”，不静默按零结算。
- 已提现后退款涉及的打手报酬差额由财务人工确认并登记处理结果，不自动扣减打手后续收入。
- 当前工时不参与工资计算；工资按工时计薪和迟到缺勤扣款尚未开放。
- 排班先保存为“待登记”，不累计实际工时；到岗后由人事登记实际工时。未来日期不能提前登记到岗，编辑备注会保留已登记的实际工时。

## 数据与后续工作

初始开发数据仅用于验证页面与流程，界面明确标示示例数据。正式使用前应通过独立的新数据库建立正式账号与配置，保留测试库用于验证。

独立打手端 UI 尚待下一阶段开发，相关接口见 `server/README.md` 和 `STUDIO-CONTRACT.md`。提现最低金额、频次、手续费、分币尾差及具体发薪日期等未确认规则继续保留为配置 / 待定事项；未确认的自动扣款规则不直接落地。
