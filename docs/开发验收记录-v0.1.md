# 工作室后台 v0.1 本地验收记录

日期：2026-10-12。当前交付范围为管理后台、持久化 API 和后续独立打手端接口；尚未发布公网，独立打手端 UI 待下一阶段开发。

## 已实现

- 数据概览、快捷下单、订单列表与详情、派单调整、取消与补偿、财务验收。
- 订单模板及价格快照、来源与闲鱼店铺、等级开放时间、接单上限、人员与客户档案。
- 角色默认权限与个人覆盖，服务端过滤工资、利润、佣金及审计内容。
- 退款申请与处理、提现审核与人工发放登记、费用及可恢复删除、工资方案与发放快照、退款提成差额及同月补结算。
- 收入与订单成本按原付款日归属，工资提成按订单完成月份归属；缺失工资配置阻止结算。
- 先排班后登记到岗、人工实际工时、跨夜班次、请假和缺勤、操作日志。
- SQLite 业务、附件、密码哈希及会话持久化；金额使用整数分。
- 直接改造 Art Design Pro 原工作台、经营报表、人员、角色、菜单及个人中心；订单、财务、配置和考勤复用原搜索栏、表格、图表与表单。全站共用原入口、动态路由、布局、Pinia 和主题。
- 移除此前另做的独立应用、页面包装器和独立全局样式；未删除原项目组件、模板及功能示例。原电商模板移到模板中心，并保留旧地址跳转。
- 保留原模板路由及示例页面，示例数据与工作室业务区分。原权限切换示例仅在该页面预览角色，不替换真实登录。
- 独立的超级管理员角色及服务端保护；旧版初始 admin 迁移时保留业务、密码及会话。
- 原个人中心可真实修改称呼和密码，改密撤销全部会话；原注册与忘记密码页说明管理员建号及重置流程。

## 用户确认的补充规则

2026-10-12 用户选择：打手已经提现后发生退款，先由财务人工确认差额并登记处理结果。系统标记人工待处理，保留说明，不自动扣减后续收入或产生负余额。

## 验证

- `pnpm test`：23 项自动测试，覆盖实际 HTTP 鉴权、并发抢单和提现、角色数据隔离、重复验收与结算、部分退款提成扣回、补发工资、取消补偿、费用恢复、附件权限、排班考勤、超管防越权、旧数据迁移及 SQLite 重启，新增服务器角色默认权限和本人资料、密码及会话撤销验证。
- `pnpm build`：执行 Vue / TypeScript 类型检查并生成生产构建。
- 原生页面浏览器验收使用独立内存数据库，不增加真实本地数据库中的测试记录。覆盖业务页面、原模板及组件示例，以及真实客户建档、下单、修改和凭证上传。
- 联调发现并修复：金额输入的原生步长校验、订单模板多语句解析、权限响应中的佣金快照、未配置运营归属的补齐、实际工时被编辑覆盖、未来排班提前计入到岗。
- 人员与个人中心浏览器验证：真实新增员工和打手、编辑权限、等级与接单上限；普通管理员不能维护超管；角色读取服务器默认权限、菜单树展开收起、称呼修改和密码更新。模拟改密后的退出请求断网，本地仍正确退出，旧密码不能登录，新密码可登录。检查期间没有页面运行错误。
- 原生业务生产构建验证：打开 16 个业务和原示例地址；真实建立客户、创建 88 元闲鱼订单、修改房间码并记录原因；上传图片并登记 12.34 元费用；切换核算月份。多标签页、垂直/水平菜单、深浅主题及刷新保留、390px 手机布局、真实退出均通过，页面运行错误为 0。
- 权限浏览器验证：10 类角色菜单与受限深链均通过；打手隐藏的个人中心仍可访问；运行中授权、撤权及撤空全部权限后刷新同步。仅剩隐藏个人中心的父目录从菜单隐藏，路由保留。页面运行错误为 0。

## 数据报表导出补充验收（2026-10-13）

- 新增“数据报表 → 自选导出”，25 类真实业务报表可独立选择字段。订单、财务、工资、考勤、人员与权限、客户与配置、经营统计、日志及本人资料均有导出内容；业务页提供快捷入口。
- 支持核算月份、明细日期范围、订单日期口径、相关人员、来源、状态和关键词；预览前 20 条，下载全部筛选记录，单次合计上限 100,000 条。
- 扩展原 `ArtExcelExport`，原 Excel 示例继续可下载。多个模块同一工作簿，字段严格按选择输出，金额保留数值，长订单号和前导零保留文本，看似公式的文本不会变成公式；空表保留表头，缺配置保留“待配置”。
- `pnpm test` 共 40 项通过，新增导出数据权限、实际 HTTP 鉴权、权限撤销、全量日志、上海日期口径、字段投影及 Excel 文件往返测试。生产构建通过。
- 独立内存数据库浏览器验收：实际下载全部 25 模块、只选订单四个字段、导出客户、筛选空表、预览、业务页快捷入口、390px 手机布局及原 Excel 示例。下载后的文件读取核对通过，页面运行错误为 0，未修改真实本地业务数据。
