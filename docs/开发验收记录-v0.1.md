# 工作室后台 v0.1 本地验收记录

日期：2026-10-12。当前交付范围为管理后台、持久化 API 和后续独立打手端接口；尚未发布公网，独立打手端 UI 待下一阶段开发。

## 已实现

- 数据概览、快捷下单、订单列表与详情、派单调整、取消与补偿、财务验收。
- 订单模板及价格快照、来源与闲鱼店铺、等级开放时间、接单上限、人员与客户档案。
- 角色默认权限与个人覆盖，服务端过滤工资、利润、佣金及审计内容。
- 退款申请与处理、提现审核与人工发放登记、费用及可恢复删除、工资方案与发放快照、退款提成差额及同月补结算。
- 收入与订单成本按原付款日归属，工资提成按订单完成月份归属；缺失工资配置阻止结算。
- 先排班后登记到岗、人工实际工时、跨夜班次、请假和缺勤、操作日志。
- SQLite 业务、附件、密码哈希及会话持久化；金额使用整数分。

## 用户确认的补充规则

2026-10-12 用户选择：打手已经提现后发生退款，先由财务人工确认差额并登记处理结果。系统标记人工待处理，保留说明，不自动扣减后续收入或产生负余额。

## 验证

- `pnpm test`：19 项自动测试，覆盖实际 HTTP 鉴权、并发抢单和提现、角色数据隔离、重复验收与结算、部分退款提成扣回、补发工资、取消补偿、费用恢复、附件权限、排班考勤及 SQLite 重启。
- `pnpm build`：执行 Vue / TypeScript 类型检查并生成生产构建。
- 浏览器：登录、打开全部 8 个模块；实际创建 88 元闲鱼测试订单，修改房间码，验证详情及修改前后日志。测试订单明确标记为本地验证用途，保留在被 Git 忽略的演示数据库中。
- 联调发现并修复：金额输入的原生步长校验、订单模板多语句解析、权限响应中的佣金快照、未配置运营归属的补齐、实际工时被编辑覆盖、未来排班提前计入到岗。

## 待下一阶段

独立打手端 UI、真实业务账号和金额比例配置、未确认的提现规则与双人分币尾差、生产部署和备份。管理后台不提供客服代接单、代上报或代提现入口。
